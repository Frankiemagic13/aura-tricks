# aura-tricks
## AuraKit (Aura version 8 features)

`aurakit/` holds a copy of AuraKit, the Aura developer's framework: volume buttons as triggers,
close the App Clip, status bar, rotation lock, Liquid Glass buttons, and more.
See [aurakit/README.md](aurakit/README.md). Test page: `aura8/`.

`kill.js` now closes a past spectator's App Clip (Aura 8). If it cannot close, it goes to apple.com.
