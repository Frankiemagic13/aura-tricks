Help

1. Close the Cosmos app and the PeekSmith app, and turn off Atom. The printer accepts one connection at a time.

2. Tap Connect. In Aura it searches for the Cosmos (LuckP_L2…). In Chrome, choose it in the list.

3. Type the text, choose a handwriting and size. The preview shows exactly what prints (black dots only).

4. Tap Print. "Printed ✓" means the Cosmos sent its done signal.

Keep this page on screen while it prints. If the text comes out upside down, turn on Upside down.

Works in Aura Browser (iPhone) and Chrome (Mac). Safari has no Bluetooth for web pages.

PeekSmith: only in Aura Browser. Close the PeekSmith app first. The Cosmos and the PeekSmith can be connected at the same time. Set what each PeekSmith button does in the PeekSmith card.

Print last Inject: the page gets the last word sent to Inject (your Inject ID) and prints it with the same handwriting. Use {word} in "Inject text" to add your own words around it.
