First video (API key): the page finds the first video for the peek and plays it. "This page" plays it here, full screen, so the page keeps listening and the next peek plays the next video. "YouTube app" opens the video in the app, where it plays. The key stays on this phone only (it is not saved on GitHub). First video (no key): the page goes to the first result through DuckDuckGo. It usually is a YouTube video, but not always, and it opens in the browser. Dot: when a peek comes in, a small dot shows for 1.5 s (set its color, place and size above; "Show the dot for 3 s" closes the settings so you can see it) (with "after a tap" it stays until the tap). Start at: the video starts at this time, for example 0:45 or 1:30 (empty = from the beginning). Search results only: the old way. YouTube app, after a tap: when a peek comes, nothing shows; the next tap anywhere on the black screen opens the video in the YouTube app, with no "Open in YouTube?" box (iPhone needs a real tap on a link for that).
Get a free key: console.cloud.google.com → create a project → APIs & Services → Library → "YouTube Data API v3" → Enable → Credentials → Create credentials → API key. Free use is about 100 searches per day.
Most views (top 10): of the 10 best matches for the peek, the page plays the video with the most views. This is better than sorting all of YouTube by views, which can give a popular video that does not match.
Wait before opening: the page opens YouTube only when the peek has not changed for this time. This stops the calculator from opening YouTube after each number. If "Open automatically" is off, tap the black screen to open the last peek.
Test text
Sound on "This page": iPhone can block sound that starts without a tap. Then the video plays without sound, and one tap anywhere turns the sound on. Some apps (Aura included) can block the YouTube app link. If "YouTube app" does nothing, select "YouTube web page".
