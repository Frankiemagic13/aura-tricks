Help

Open settings: push and hold the # key for 1 second.

Set the number: copy a phone number. Open Phone number and push Paste. You can also type the number.

Trigger: select "First key tap" or "Call button". When the spectator does this, the screen glitches.

The effect: the screen glitches for approximately 2 seconds. Then your number shows on the display and the phone calls it.

Reset: when you come back to the page after the call, the display is empty again.

Note: iOS can show a "Call" prompt before it dials. This is an iOS rule for web pages.
